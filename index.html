Four side projects living under ~/code/2026. Each one started as a question — about markets, about cinema, about how I learn, about how property tickets should feel — and turned into something I could actually run.

fingod

Market-data pipeline · Python · Streamlit · React

A small market-data pipeline for a personal investment-advisory tool. Tracks UK OEICs, LSE-listed stocks and US stocks; pulls daily prices, extracts OEIC ongoing-charge figures from KIID PDFs, and surfaces everything through a Streamlit UI and a Vite + React SPA over a thin FastAPI shim.

aiquiz

ATCV self-test · Static HTML · GitHub Pages

An interactive self-test quiz for EEEM071 — Advanced Topics in Computer Vision at the University of Surrey. Covers the full L1–L25 lecture series with multiple-choice questions, instant feedback, explanations, flagging, wrong-only review, and localStorage-backed progress.

cine_nova / filmcraft

AI storyboard pipeline · AWS Bedrock · FastAPI · React

An AI-powered storyboard pipeline that turns a script into a visual storyboard — beats, shot lists, cinematic instructions, and generated images — using AWS Bedrock (Nova Pro + Nova Canvas). Export to MP4, PDF or GIF.
